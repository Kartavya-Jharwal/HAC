01 / Development Setup

Bootstrapping Your Repo

Ready to go live? Let's map your shiny new domain to your existing Code layout. This is a rapid 4-10 minute setup meant to instantly elevate your positioning.

1. Codes
2. Route
3. Address
4. DNS

1

Prep Your Codes

Before ever leaving Code, make sure your site is properly dressed for the spotlight. Click Publish Website and enable the following settings:

  • Set a polished Site Title and a custom Favicon.
  • Toggle on Search Engine Visibility so recruiters can actually Google you.
  • Enable the Navigation Menu, Resize on Mobile, and Social Media Link Preview capabilities.
2

Route Your Domain

Once you proceed through publishing, select Use my existing domain. Code will check the market for the domain you want:

  • If it's strictly on the market, Code will try to direct you to their own domain store.
  • Alternatively, you can buy on private third-party domain servers (we recommend Namecheap, Name.com, or GoDaddy).
3

Acquire Your Free Address (Education Route)

If you're a student, you can skip the purchase completely. We utilize the GitHub Education platform as an essential frugal resource.

  • Head over to the GitHub Education portal and get set up using your Student ID and `.edu` email.
  • Once accepted, locate the Namecheap or Name.com offer to claim your first year completely free.

Note: GitHub is inherently a technical platform usually for developers. We use it purely for the massive free domain discount it offers to students. There are multiple other platforms you can explore for domains at your disposal, but this is the best financial hack.

4

Connect the Dots (DNS Records)

This is where we introduce your new address to your Code design. Keep Code open, then log into your domain server (like Namecheap) and navigate to the Advanced DNS settings.

  • First, add an A Record block using the specific Values Code generated.
  • Next, copy the TXT Record code from Code and add it to verify your ownership.
  • Ensure everything is saved. Your completed DNS records page will eventually confirm all elements match.
5

Final Code Management

Return to Code. It will ask if you want to explicitly use this newly mapped domain for this project. Confirm your choice.

Post-Setup Codes: You can manage your routing over time in your settings.

  • Domains Hub: Under your Settings > Domains tab, you can view your real estate portfolio.
  • Third-Party Overviews: Outlines domains managed natively vs external hubs.
  • Individual Domain Detail: Click into any active domain to see its record verification, active status, as well as add URL redirects.
02 / Go Live

Verify Your Setup Works

DNS Propagation can take anywhere from 15 minutes to 48 hours. Here's how to check if your new storefront is open globally:

  • Ping DNSChecker.org: Enter your custom domain and select 'A Record'. If you see green ticks worldwide matching the Code IP, you're live.
  • Test on Mobile: Disconnect from WiFi. Does your website load properly on a cellular data network?
  • Check the Lock: Ensure the HTTPS lock icon appears next to your URL. Code provisions an SSL certificate automatically, but it can take an hour to issue.
03 / Future Proof

What to Do in Year 2

If you used the GitHub Education deal, congratulations—your first year is entirely free. However, domains renew annually.

The Renewal Reality:
Usually, a standard `.com` or `.me` costs roughly $10-15/year upon renewal. Keep an eye on your registrar emails to ensure your card is linked to avoid your domain expiring and being bought by a broker. If you want to migrate, you can unlock and transfer your domain to a cheaper registrar right before renewal!

06 / The Lexicon

Agency Recruiter's Guide to Web Jargon

Translations for the technical terms you'll inevitably encounter during this operation.

DNS (Domain Name System)
The internet's contact book. It simply matches human-friendly URLs to physical server addresses.
A Record (Address)
The specific line of code that commands your domain to point straight to Code's servers.
TXT Record
A hidden notepad rule. Code uses this to securely verify that you actually own the domain you claim.
Propagation
The global waiting period. The time it takes for servers worldwide to finish synchronizing their address books with your new URL.
